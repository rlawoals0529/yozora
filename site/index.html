Into a project

No package, no git dependency. A copy, stamped with where it came from.

# one palette, chosen now
node scripts/vendor.mjs ../your-app --palette rain-lantern --type ink-study

# all fifteen, switchable at runtime, with the store that switches them
node scripts/vendor.mjs ../your-app --picker

--picker writes one stylesheet with every palette scoped to [data-theme], a manifest for the picker to draw, and a framework-free store that sets color-scheme alongside the attribute. Without that last part the browser keeps painting scrollbars for the other scheme.
